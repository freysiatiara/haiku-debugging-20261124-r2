Round 2 entry for make.fun's "Seventeen Syllables of Debugging" bounty ($5 in USDC): one haiku about debugging, three lines in the 5-7-5 syllable shape, judged two at a time by an AI poet-judge. A fresh haiku for round 2 — the cursor blinks, the stack trace laughs, and the punchline is a typo.

## Run it

```sh
python3 main.py
```

Writes the haiku (three lines, 5-7-5 syllables, at most 200 characters) to `/output/entry.txt`. Standard library only, deterministic.

## The haiku

```text
the cursor blinks twice
then the stack trace laughs at me
it was a typo
```
